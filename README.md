## Project Overview
This repository contains the complete frontend architecture for Rethabile's Flame Burger, a high-energy local fast-casual dining small business. The platform bridges the gap between physical storefront sales and digital outreach, offering customers an optimized interface to browse extensive food menus, learn about corporate bulk catering guidelines, and find physical store directions.

## Website Goals and Objectives
Primary Goal: Increase the physical footprint engagement from our Gauteng branches.
Operational Goal: Systematize large party and bulk click-and-collect orders without requiring interactive client database forms.
KPI Matrix: Achieve high-ranking organic visibility on local search maps and maximize casual visitor conversion metrics.

## Features and Functionality
Unified Menu Showcase: Displays full beef, chicken, beverage, and dessert milkshake pricing in a clean catalog template.
Static Enquiry FAQ Hub: Provides information on group events and catering guidelines.
Multi-Location Contact Blocks: Outlines store coordinates for Hatfield (Pretoria) and Maboneng (Johannesburg).

## Sitemap
Our website platform uses a flat navigation structure to make sure customers can find information quickly. The main homepage serves as the central entry point, and it links directly to the other four pages. To keep the user experience consistent, every page on the site shares the exact same header navigation menu bar at the top and the legal copyright footer block at the bottom.

* The home screen is mapped to index.html and serves as the primary landing page.
* The about us screen is mapped to about.html and holds the business background story.
* The menu and products screen is mapped to products.html and shows the food items.
* The enquiries screen is mapped to enquiries.html and functions as the booking FAQ hub.
* The contact screen is mapped to contact.html and displays our store location blocks.
